CV Builder Web App

A fully responsive CV Builder web application developed using HTML, CSS, and JavaScript as part of my Web Engineering semester project.

This application allows users to select from multiple professionally designed resume templates, enter their details, and instantly generate a structured CV layout.

🚀 Features

10 Ready-to-Use CV Templates

5 Modern Templates

3 Professional Templates

2 Basic Templates

Dynamic template rendering using JavaScript

Real-time user input handling

Clean and intuitive UI/UX

Fully responsive design (mobile, tablet, desktop)

Organized and structured resume layout generation

🛠 Tech Stack

HTML5

CSS3

JavaScript 

No external frameworks or libraries were used. The focus was on strengthening core frontend fundamentals and DOM manipulation skills.

📌 How It Works

User selects a CV template.

User enters personal and professional details.

The system dynamically injects the data into the selected template.

A clean, structured CV layout is generated instantly.

🎯 Learning Outcomes

Improved understanding of DOM manipulation

Responsive layout structuring

Reusable template-based rendering

Managing user flow and dynamic content updates

Strengthened frontend fundamentals without relying on frameworks
